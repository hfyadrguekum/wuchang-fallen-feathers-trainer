## 📖 About

WUCHANG: Fallen Feathers by Leenzee Games (2025) is a soulslike set in Ming dynasty China with Lovecraftian corruption. You play as Wuchang, a woman with fractured memory, in a world where the Feathering plague turns humans into monstrous beasts. Its combat blends Chinese martial arts with sanity mechanics.
